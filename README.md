# Digital Agency Website 💜

A responsive digital agency website recreated from a Figma design using **React** and **Tailwind CSS**.

This project was built as a frontend practice project to improve my React skills and explore modern UI techniques while creating a complete responsive website from scratch.

## ✨ Features

* 📱 Fully responsive design
* 🌙 Light and dark mode
* 🎨 Interactive gradient card borders
* 🖱️ Custom cursor
* ✨ Scroll animations with Motion
* 🧩 Reusable React components
* 📩 Functional contact form using Web3Forms
* 🔔 Toast notifications
* 📱 Responsive navigation
* 🏢 Services section
* 💼 Latest work section
* 👥 Team section
* 📬 Contact section
* 🦶 Responsive footer

## 🛠️ Technologies

* React

The website was recreated from a Figma design as part of my frontend development practice.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Chahd-TB/react-digital-agency.git
```

### 2. Navigate to the project

```bash
cd react-digital-agency
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The project will then be available locally through the Vite development server.
